# NOVAUDIOVISUAL

Portal de realizadores audiovisuales: trabajos, fondos, festivales y comunidad en un solo lugar.

**Sitio:** https://simonrovi-web.github.io/novaudiovisual/

## Paneles
- **Trabajos** (`novaudiovisual-trabajos.html`): busca un oficio en 18 portales de empleo, freelance y crew a la vez.
- **Fondos y festivales** (`novaudiovisual-fondos.html`): calendario de convocatorias con fechas confirmadas y estimadas.

Sitio estático (HTML + CSS + JS, sin build). Información referencial: los enlaces llevan a sitios de terceros.

## Probar en local
```bash
python -m http.server 5520
```
